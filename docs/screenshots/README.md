# ShopVerse — UI Screenshots

Captured at 1440×900px, full-page, using Playwright against the live dev server.  
**Date:** 2026-05-10 | **Version:** v1.0

To regenerate:
```bash
# Start servers first
cd backend && npm run start:dev &
cd frontend && npm run dev &

# Then from frontend/
node screenshots.mjs
```
