# Code of Conduct

This project has adopted the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

By participating in this community, you agree to abide by its terms.

## Reporting

If you experience or witness any behavior that violates this Code of Conduct,
please report it confidentially to the project maintainer:

**Email:** vivironycrazy@gmail.com

All reports will be reviewed and investigated promptly and fairly. The reporter's
identity will be kept confidential.

## Enforcement

Project maintainers are responsible for clarifying and enforcing the standards of
acceptable behavior. They have the right to remove, edit, or reject contributions
that are not aligned with this Code of Conduct, and to ban contributors whose
behavior they deem inappropriate.

## Scope

This Code of Conduct applies in all project spaces — issues, pull/merge requests,
discussions, code review, chat channels, and any in-person or virtual events
representing the project — and when an individual is officially representing the
project in public spaces.

For the full text, examples of unacceptable behavior, and the four-step enforcement
ladder (correction → warning → temporary ban → permanent ban), see the upstream
document linked at the top of this file.
