# Support

Thanks for using ShopVerse. Here's where to go for help.

## Bugs

File an issue using the **Bug Report** template:
https://gitlab.com/aiexperts/ecommWeb/-/issues

Please include:
- Steps to reproduce
- Expected vs actual behavior
- Environment (OS, Node version, Postgres version, Docker vs manual install)
- Relevant log output or stack traces (with secrets redacted)

## Feature requests

File an issue using the **Feature Request** template at the link above.
Describe the user problem first, then the proposed solution. Feature requests
that come with a draft design or POC are merged ~5× faster.

## Questions and discussion

For now, open an issue with the label `question`. Threaded Discussions are
planned (see `ROADMAP.md`).

## Security vulnerabilities

**Do not file public issues for security problems.** Follow the coordinated
disclosure process in [`SECURITY.md`](SECURITY.md).

48-hour acknowledgement SLA, 30-day fix-or-mitigation target.
